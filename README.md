# 羽村市議会 横断検索シンプル版

モダンで軽量な議事録検索デモです。キーワード検索に加え、開催種別・テーマ・年度・発言者で絞り込めます。サンプルデータを同梱しているので、セットアップ後すぐに動作を確認できます。

## 使い方

### 1. セットアップ

Python 3.10+ を用意した上で依存関係をインストールします。

```bash
pip install -r requirements.txt
```

### 2. アプリを起動

```bash
python app.py
```

ブラウザで <http://localhost:5000/> を開くと検索画面が表示されます。

## 機能概要
- キーワードによる横断検索（議題・概要・本文を対象）
- 開催種別・テーマ・年度・発言者の組み合わせフィルター
- 本文抜粋にヒット箇所をハイライト表示
- JSON 形式の `/api/search` エンドポイント

## データ

`data/meetings.json` に6件の架空の議事録サンプルを収録しています。年度やテーマがばらけているので検索や絞り込みの動作確認に利用できます。
