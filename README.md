# 羽村市議会 横断検索シンプル版

ダウンロードしてフォルダを開いたら、`index.html` をブラウザで開くだけで動くスタンドアロンの議事録検索デモです。インストールやサーバー起動は不要です。

## 使い方
1. このディレクトリを任意の場所に配置し、`index.html` をブラウザで開きます。
2. キーワード・開催種別・テーマ・年度・発言者を指定して検索します。
3. 条件をリセットする場合は「条件をクリア」を押してください。

※ ブラウザのセキュリティ設定によってローカルファイルの読み込みが制限される場合は、`python -m http.server 8000` などで簡易サーバーを立てて `http://localhost:8000` を開いてください。

## 機能概要
- オフラインで完結するクライアントサイド検索
- キーワード検索（タイトル・概要・本文を対象、スペース区切り複数ワード対応）
- 開催種別・テーマ・年度・発言者の組み合わせフィルター
- 本文抜粋の自動生成とヒット箇所ハイライト
- サンプルデータ6件を同梱（`data/meetings.js` / `data/meetings.json`）

## ファイル構成
- `index.html`: 検索画面と検索ロジックを含む単一ページ
- `static/style.css`: スタイルシート
- `data/meetings.js`: ブラウザで読み込むサンプルデータ
- `data/meetings.json`: サンプルデータのJSON版（編集・差し替え用）
